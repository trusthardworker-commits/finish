# Лавка логопеда — магазин и CMS

Интернет-магазин с админкой. Бэкенд — Python 3.10+ (стандартная библиотека) + SQLite; для проверки и перекодирования загружаемых картинок нужен Pillow. Фронтенд — статический HTML/CSS/JS без сборки.

## Запуск (локально)
```bash
cp .env.example .env            # по желанию; переменные читаются из окружения процесса
python3 server/app.py           # http://127.0.0.1:8000, админка: /admin/
```
При первом запуске создаётся база `data/shop.db`, структура категорий и **демо-товары** (`LP_SEED_DEMO=0` — не создавать демо). Если `LP_ADMIN_PASSWORD` не задан, пароль администратора (логин `admin`) генерируется и **один раз** выводится в консоль. Смена пароля: `python3 server/app.py --reset-admin`.

Тесты: `python3 tests/test_api.py` (26 тестов API, безопасность и негативные сценарии).
Резервная копия БД: `python3 server/app.py --backup` → `data/backups/` (настройте регулярный запуск по cron; копируйте также `data/uploads/`).

## Структура
- `server/app.py` — API, админ-API, сессии, миграции БД (`PRAGMA user_version`), раздача статики.
- `public/` — сайт (`index.html`, `js/app.js`, `css/`) и админка (`admin/`).
- `tests/test_api.py`, `docs/AUDIT.md` — тесты и отчёт аудита.
- `data/` — БД и загрузки (не в git).

## Что управляется из админки
Товары (создание, правка, скрытие/публикация/архив, удаление с проверкой заказов, цена, остаток, категория, рекомендуемый, порядок, SEO, изображения), категории и направления («Логопедические товары» / «Канцелярия»), баннер главной (заголовок, подзаголовок, кнопки, изображение), блок «Товары в наличии», тексты страниц («О нас», «Доставка и оплата», «Контакты», «Политика ПДн», «Для детских садов»), заказы и их статусы, журнал действий.

## Что нужно сделать перед запуском в продакшн
См. `docs/AUDIT.md`, разделы «Оставшиеся риски» и «Настройка сервера». Главное: HTTPS на reverse proxy и `LP_SECURE_COOKIES=1`, заполнить реальные товары и юридические тексты, настроить резервное копирование, уведомления о заказах, при необходимости — оплату.
